- 분석 캐싱 (5분 TTL, 최대 50개) → 같은 스레드 재클릭 시 즉시 표시

- 라벨 필터 (받은편지함/보낸편지함/별표/중요)
- 키보드 단축키 (j/k 이동, / 검색, r 재분석, Esc 닫기)
- 전체답장(Reply-All) CC 지원
- 최근 메시지 발신자 + 날짜 표시 (스레드 목록에서)

## 2026-04-25

### 개인별 메일 발송 기능
- 메일 작성/답장 에디터에 "개인별로 보내기" 체크박스 추가
- 체크 시 To 수신자 목록을 한 명씩 나누어 각각 별도 Gmail 메시지로 전송
- 첨부파일 없음: `/api/send`가 `sendIndividually` 옵션을 받아 서버에서 순차 전송
- 첨부파일 있음: `sendMailDirect`를 수신자별로 반복 호출해 Gmail API 직접 전송
- 전송 확인 모달과 완료 토스트에 개인별 발송 건수 표시
